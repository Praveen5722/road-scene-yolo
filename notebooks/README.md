# Notebooks

`road_scene_yolo.ipynb` is the main end-to-end PBL notebook for this project.

It demonstrates:
- YOLOv8 road-object detection
- scene understanding (left/ahead/right and near/far)
- hazard warnings
- video inference and tracking
- COCO8 evaluation
- optional KITTI fine-tuning

Open `road_scene_yolo.ipynb` in GitHub or Jupyter/Google Colab to run it.
